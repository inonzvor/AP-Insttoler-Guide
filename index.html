the whole job, in order

Never installed one of these before? This is the full sequence. Do the steps in order; each card links to the detail you need for that step.

01 Pick a model Match the site — mount type and load — to one of the 8 access points. 02 Understand the device Read the model page: ports, power options, what's in the box, watch‑outs. 03 Power it — PoE or adapter PoE switch, PoE injector, or a 12 V DC adapter on models that support it. 04 Find it on the network Use the SADP tool or the router's DHCP list to get the AP's IP address. 05 Activate it The unit ships inactive — set a strong admin password, then its IP mode. 06 Configure it Web UI, Hik‑Partner Pro, or a wireless controller — pick the right one. 07 Verify & hand over Signal walk, speed and roaming test, record credentials, hand to the customer.

Start here

the whole job, in order

Never installed one of these before? This is the full sequence. Do the steps in order; each card links to the detail you need for that step.

Step 1 →
Pick a model Match the site — mount type and load — to one of the 8 access points.
Step 2 →
Understand the device Read the model page: ports, power options, what's in the box, watch‑outs.
Step 3 →
Power it — PoE or adapter PoE switch, PoE injector, or a 12 V DC adapter on models that support it.
Step 4 →
Find it on the network Use the SADP tool or the router's DHCP list to get the AP's IP address.
Step 5 →
Activate it The unit ships inactive — set a strong admin password, then its IP mode.
Step 6 →
Configure it Web UI, Hik‑Partner Pro, or a wireless controller — pick the right one.
Step 7 →
Verify & hand over Signal walk, speed and roaming test, record credentials, hand to the customer.
